## 📦 installstep

### 1. downloadinstall

 [Releasespage](https://github.com/autoclip/autoclip/releases) downloadinstall：

- **macOS (Apple Silicon)**: `AutoClip-Desktop-1.0.0-arm64.dmg`
- **macOS (Intel)**: `AutoClip-Desktop-1.0.0-x64.dmg`
- **Windows**: `AutoClip-Desktop-1.0.0-x64.exe`
- **Linux**: `AutoClip-Desktop-1.0.0-x64.AppImage`

### 2. install

#### macOS
1. download `.dmg` file
2.  `AutoClip Desktop`  `Applications` file
3. ，"verify"，：
   - open `settings` > `security`
   - click `open` button

#### Windows
1. download `.exe` file
2. installcompletedinstall
3. installcompleted，start

#### Linux
1. AppImagefile：
   ```bash
   chmod +x AutoClip-Desktop-1.0.0-x64.AppImage
   ```
2. ，：
   ```bash
   ./AutoClip-Desktop-1.0.0-x64.AppImage
   ```
